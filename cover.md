This webpage is an interactive version of the notes I compiled for the course ME415 from slides, reference books, past papers, textbooks and class notes, with the help of Claude Opus 5.5 coding agents. The PDFs of each module can be found in this [Google Drive folder](https://drive.google.com/drive/folders/1y_JbyRe-R0PATAXR8Gg5uFLyWEvhi0-4?usp=drive_link).

Each module covers one topic. *The modules are not ordered by the slides* or by any other source: this is a design choice, to keep the study experience seamless.

## Organization

- **Module is All You Need.** The entire note is organized around modules. Each module is self-contained and independent of the other modules, with reasonable prerequisites assumed. It is designed to save you the time of browsing several sources, so that you can focus only on understanding.
- Modules are divided into sections. An ideal section introduces a concept, clarifies it with an example and ends with questions, drawn from the sources or generated by an LLM. The sources are cited, and LLM-generated material is flagged.
- Numerical problems and examples are developed step by step. If you are stuck, you can reveal a hint, or expand the solution of that particular step. Looking up a table does not require you to leave the notes: the table pops up when you click a value.
- The modules are ordered roughly by their weight in the exam: the earlier modules carry the most marks.

## Contributing

The GitHub repository of this note is [github.com/Imdadullah-Raji/me415-notes](https://github.com/Imdadullah-Raji/me415-notes). It contains both the content and the code.

The judgement should be yours. You, the reader, know best what you find lacking here. The execution can be relegated to coding agents; that is how these notes have reached you.

To contribute:

- Edit the markdown (GitHub's web editor is enough) and open a pull request. The build checks every pull request.
- The build must pass: it fails if a value read from a table differs from the data book, or if a link is broken.
- Every worked numerical is a sequence of steps, each with a hint; every value read from the data book is wrapped so that it opens the table.
- The full rules and the markup are in [CONTRIBUTING.md](https://github.com/Imdadullah-Raji/me415-notes/blob/main/CONTRIBUTING.md).
